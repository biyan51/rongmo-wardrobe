# Wardrobe maintenance

- This website is public and requires no login for visitors. Do not add a sign-in requirement.
- Shared wardrobe data is in data/wardrobe.json. Read the latest file and its SHA before authorized updates; preserve unrelated user changes, bump revision, and update updatedAt.
- Clothing photographs belong in same-site paths such as photos/. Silhouettes are illustrations, not actual photographs. Keep rule-generated suggestions labeled.
- Wear history is browser-local. Never claim cloud synchronization, device-to-device synchronization, or recovery after browser-data deletion.
- Publishing source is intended to be main /(root) through GitHub Pages. Uploading files alone does not verify publication or direct access from the user's network.
- Do not store tokens, secrets, private wear records, or personal documents in this public repository. No unattended updates have been configured.
